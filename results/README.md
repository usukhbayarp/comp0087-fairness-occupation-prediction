# Introduction
This directory contains the results of the experiments. Do not add any files to this directory.

# Directory Structure

- `predictions/`: JSONL files for encoder predictions
- `pythia/`: Zero-shot and few-shot Pythia predictions
- `pythia_finetuned/`: Fine-tuned Pythia predictions (masked and unmasked)
- `proxy/`: Aggregated proxy-token CSVs per profession
- `compare/`: Masked vs. unmasked comparison and summary CSVs
- `faithfulness/`: Erasure faithfulness scores
- `counterfactual/`: Counterfactual pronoun-swap results
- `tables/`: CSV results including summary_results.csv and detailed_fairness.csv
- `figures/`: Generated visualisations from the evaluation script, including pareto frontiers, correlation plots, and scaling laws.
